# Programming Curiosity

> This repository is not about memorizing programming answers.
> It is about understanding WHY, WHAT, HOW, WHERE, WHEN, WHO and WHAT IF behind the technology we use every day.
> Every question is an opportunity to go one level deeper.
> Don't just learn code. Understand what happens behind the code.

## Sections Overview

### 01 — Programming Basics
Why programming exists, what languages are, and how code actually runs from text to execution.

### 02 — Variables and Memory
How variables work, what memory is, the difference between stack and heap, and how garbage collection reclaims memory.

### 03 — How Programs Run
Compilers vs interpreters, what a process is, and how threads enable concurrent execution.

### 04 — Internet
How DNS resolves names to IPs, how IP routes packets, and how HTTP/HTTPS power web communication.

### 05 — APIs
What an API is, the request-response cycle, and how REST structures web services.

### 06 — Databases
Relational (SQL) vs non-relational (NoSQL) databases, how indexes speed up queries, and how transactions keep data consistent.

### 07 — Security
The difference between authentication and authorization, why hashing protects passwords, and how encryption works.

### 08 — Cloud and Deployment
What a server is, how cloud computing works, and how systems scale to handle more load.

### 09 — Language Comparisons
Deep dives into Python, JavaScript, and Java — their strengths, weaknesses, and when to use each.

### 10 — Rabbit Holes
End-to-end narratives tracing what happens when you run code, open Google, or log in to a website — connecting every concept from the previous sections.

## The 7-Question Framework

Whenever you learn something, ask 7 questions:

**WHY? → WHAT? → HOW? → WHERE? → WHEN? → WHO? → WHAT IF?**

A good programmer doesn't just learn answers. A good programmer develops better questions.
